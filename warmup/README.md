# Warmup

Small C exercises done before the main assignment, exploring the
language/OS features [thread-library](../thread-library) and
[backtracking-rollback](../backtracking-rollback) build on:

- `uctx.c`, `print_uctx.c` — saving/swapping/inspecting execution
  contexts with `ucontext.h` (the mechanism the thread library is built
  on).
- `fptr.c`, `fptr_min.c` — function pointers.
- `malloc.c`, `pointer.c` — dynamic memory and pointers.
- `struct.c`, `struct_val_ref.c`, `call_val_ref.c` — structs and
  pass-by-value vs. pass-by-reference.
